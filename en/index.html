cases --help

Usage: cases [--case ||]

Performance in production.

Three real problems I solved at Stokki, a warehouse management system (WMS) with millions of orders, measured before and after.

[1] Order picking in the Cockpit

before~65 s

after<1 s

Problem
Picking orders in the Cockpit took about 65 s, on a database with millions of orders.
What I did
In the Cockpit and Shipping modules, I moved heavy actions to queues, rewrote queries, added indexes and set timeouts on external integrations.
Result
Order picking now takes less than 1 s.

Laravel · Queues · MariaDB

[2] Order search

before15–47 s

after≤1.3 s

Problem
Order search queries took 15 to 47 s because they scanned the whole database.
What I did
Reworked the queries to use an index instead of scanning the orders table.
Result
Responses between 0.5 ms and 1.3 s.

MariaDB · Indexes · SQL

[3] Daily e-mail summary

before5,201 queries

after23 queries

Problem
Building the daily summary sent by e-mail took 5,201 database queries.
What I did
Restructured how the summary is built so it fetches the data in 23 queries.
Result
The summary became about 24× faster.

Laravel · MariaDB
